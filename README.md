# Separador de Mandados PJe

## Como Baixar

Para clonar o projeto, execute:

```bash
git clone https://github.com/christianmpc/separador-de-mandados-PJe.git && cd separador-de-mandados-PJe
```

## Como Baixar e Abrir no Xcode

Para clonar o projeto e abrir no Xcode, execute:

```bash
git clone https://github.com/christianmpc/separador-de-mandados-PJe.git && cd separador-de-mandados-PJe && open Separador\ de\ Mandados\ PJe.xcodeproj
```
